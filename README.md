- **Актуальный пакет:** [`nanocad-test-ribbon-v1.2.19.zip`](nanocad-test-ribbon-v1.2.19.zip)

  Raw: https://raw.githubusercontent.com/rublikdimas1989/Nanocad-Ribbon/main/nanocad-test-ribbon-v1.2.19.zip
